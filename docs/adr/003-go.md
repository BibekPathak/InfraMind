# ADR-003: Go for Backend and Simulator

## Status

Accepted

## Context

InfraMind requires performant, concurrent services for telemetry ingestion, API serving, and device simulation. The language must have strong tooling, fast compilation, and good concurrency primitives.

## Decision

Use Go for the backend API server and the telemetry simulator.

## Consequences

- Goroutines and channels map naturally to the event-driven architecture.
- Single binary deployment simplifies Docker images.
- Excellent standard library (net/http, slog, context).
- Chi router keeps us close to stdlib with middleware composability.
- Strong ecosystem for MQTT (paho), PostgreSQL (pgx), and config (koanf).
